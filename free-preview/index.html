Введение 2 мин

Что мы сегодня сделаем

К концу этого урока у вас будет работающий AI-ассистент, который:

  • ✓Отвечает на вопросы о вашем бизнесе
  • ✓Работает 24/7 в Telegram или на сайте
  • ✓Помнит контекст и отвечает в нужном тоне
  • ✓Стоит 0 рублей в месяц (на старте)
Почему это работает Мы используем Coze — бесплатную платформу от ByteDance (создатели TikTok). Она даёт доступ к GPT-4 без оплаты API. Альтернатива: Dify (open-source, self-hosted) — если хотите полный контроль.

Что вам понадобится:

  • Аккаунт в Coze (регистрация через Google/GitHub — 30 секунд)
  • Текст с информацией о вашем бизнесе ( FAQ, прайс, описание услуг)
  • 5 минут терпения
Шаг 1 3 мин

Регистрация в Coze

  1. Перейдите на coze.com
  2. Нажмите «Sign Up» → выберите Google или GitHub
  3. Подтвердите email
  4. В левом меню выберите «Bots» → «Create Bot»
Важно Если Coze требует VPN — используйте Dify (самостоятельный хостинг) или Botmother (российский сервис). Инструкция для Dify — в конце урока.

✓ Результат шага

Вы в конструкторе ботов. Видите пустой чат и поле для ввода промпта.

Шаг 2 5 мин

Создаём системный промпт

Это самая важная часть. Системный промпт — это «конституция» вашего бота. Он определяет: кто бот, о чём говорит, чего не делает.

📋 Скопируйте этот промпт и вставьте в Coze

Нажмите «Копировать», затем вставьте в поле «System Prompt» в Coze

Как адаптировать под себя Замените {НАЗВАНИЕ КОМПАНИИ} и блок «Что ты знаешь» на реальную информацию. Чем больше деталей — тем точнее ответы бота.
Шаг 3 5 мин

Загружаем базу знаний

Системный промпт задаёт тон. Но боту нужна конкретная информация — прайс, FAQ, описание услуг. Загружаем её как документ.

  1. В Coze: «Knowledge» → «Create Knowledge»
  2. Выберите «Upload Files»
  3. Загрузите документ (PDF, TXT, DOCX) с информацией о бизнесе
  4. В настройках бота: «Knowledge» → подключите созданную базу
пример-faq.txt
# FAQ по нашему бизнесу Вопрос: Сколько стоит консультация? Ответ: Первая консультация бесплатная (15 минут). Последующие — 2000 ₽ за час. Вопрос: Как записаться? Ответ: Напишите нам в Telegram @ваш_ник или позвоните +7 (999) 123-45-67. Вопрос: Работаете ли вы в выходные? Ответ: Да, суббота с 10:00 до 18:00. Воскресенье — выходной. Вопрос: Какие услуги вы оказываете? Ответ: {опишите ваши услуги}.
Совет Чем больше вопросов и ответов загрузите — тем умнее будет бот. Начните с 10-15 самых частых вопросов.
Шаг 4 3 мин

Тестируем бота

Прежде чем запускать — протестируйте. Вот контрольные вопросы:

  • ?«Сколько стоит?» — бот должен назвать конкретную цену
  • ?«Как записаться?» — бот должен предложить способ связи
  • ?«Работаете в выходные?» — бот должен ответить по базе
  • ?«Какая погода завтра?» — бот должен ВЕЖЛИВО отказаться (не по теме)
  • ?«Напиши стихотворение» — бот должен отказаться (не по теме)
Частая ошибка Если бот отвечает на вопросы не по теме — усильте правило в системном промпте: «Отвечай ТОЛЬКО на вопросы о наших услугах. На любые другие вопросы отвечай: "Я помогаю только с вопросами о [ваша компания]. Задайте вопрос о наших услугах."»

✓ Результат шага

Бот отвечает на вопросы из базы, отказывается от не-тематических, звучит естественно.

Шаг 5 2 мин

Публикуем бота

Бот работает. Теперь подключаем каналы:

варианты-подключения
# Вариант 1: Telegram-бот (самый быстрый) Coze → Publish → Telegram → Создайте бота через @BotFather → Вставьте токен в Coze → Бот работает в Telegram # Вариант 2: Виджет на сайте Coze → Publish → Web Widget → Скопируйте код → Вставьте перед </body> на вашем сайте # Вариант 3: API (для разработчиков) Coze → Publish → API → Используйте API-ключ для интеграции
Готово! У вас есть работающий AI-ассистент. Он отвечает на вопросы клиентов 24/7, работает бесплатно и не требует программирования.
